# evals/: every result in this project

Everything here is generated by a script; nothing is edited by hand except this index.
Scripts live in `training/` and `evaluation/`; rerunning them rewrites these files.

## classifiers/: the emotion models compared

Written by `training/04_train_classifiers.py` (predictions) and
`evaluation/01_compare_classifiers.py` (everything else).

| File | What it is |
| --- | --- |
| [comparison.md](classifiers/comparison.md) | **Start here.** All seven models: accuracy, macro / weighted precision, recall, F1, per emotion, calibration |
| `charts/overall_metrics.png` | The headline metrics side by side, deployed model in blue |
| `charts/per_class_scores.png` | Precision, recall and F1 for every emotion and model |
| `charts/confusion_matrices_all.png` | Every model's confusion matrix |
| `charts/calibration_fused.png` | Confidence vs accuracy, before and after temperature scaling |
| `confusion_matrices/<model>.png` | One confusion matrix per model |
| `metrics.json` | Every number above, per seed and averaged |
| `predictions.npz` | Dev and test probabilities of every model and seed |
| `training_summary.json` | Dev scores and best epochs per seed, chosen text variant, temperatures |

## struggles/: where the deployed model fails

Written by `evaluation/03_analyze_errors.py` (and `09_train_on_failures.py` for the train examples).

| File | What it is |
| --- | --- |
| [analytics.md](struggles/analytics.md) | **Start here.** The written breakdown, with charts |
| `charts/*.png` | Outcomes per emotion, top mistakes, accuracy by kind of utterance, Whisper cost, audio effect, label noise |
| `test_predictions.csv` | Every test utterance: gold, both models' predictions and confidence, Whisper transcript |
| `examples.md` | Utterances where the voice fixed or broke the text-only answer |
| `hard_train_examples.md` | Train utterances no model gets right (label-noise sample) |
| `summary.json` | The numbers behind analytics.md |

## replies/: the reply model

| File | Script | What it is |
| --- | --- | --- |
| [reply_compliance.md](replies/reply_compliance.md) | `evaluation/07_compare_reply_models.py` | Reply rules (length, emotion words) and speed across prompts and LLM sizes. The inputs are sitcom lines, so this is not a measure of reply quality |
| `reply_eval/<config>.csv` | same | Every reply behind that table |

## logs/

Console output of the longer runs, kept as evidence. Logs from before the reorganization
(`train_log.txt`, `reply_compliance_log.txt`,
`bench_log.txt`, `extract_log.txt`) name the scripts as they were called then; NOTES.md maps
old names to new. `face_server_log.txt` is written by a running app and is not committed.
